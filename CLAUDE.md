# portfolio-optimiser

Interactive portfolio optimiser using Modern Portfolio Theory (pandas, SciPy, Streamlit).

## Git workflow — keep GitHub constantly updated

- After every meaningful, working change, commit it and push to `origin main` right away, without asking first.
- Make small, focused commits with clear messages in the imperative mood (e.g. "Add efficient frontier plot").
- Don't commit broken code. If something is half-finished, finish it or make sure it runs before committing.
- Never commit `venv/`, secrets, API keys, or large data files.
- If you add a dependency, update `requirements.txt` in the same commit.
